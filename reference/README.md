# Checked-in reference outputs

These files are generated by `make reproduce-paper-update` and verified by `make reproduce-paper`.

JSON references are semantic normal forms: volatile timing, machine-local paths and references, identifiers derived from platform-specific artifact bytes, and Procrustes' non-semantic choice of one `OTEL_*` field as instrumentation evidence are normalized. Valid zero-value identifiers mark fields derived from platform-specific raw bytes. The source document is retained, as are contracts, topology, predicates, simulation parameters, results, confidence intervals, and sweep boundaries. The normalization rules and SHA-256 digests are recorded in `manifest.json`.

Do not edit individual reference files by hand. Update them only after reviewing changes to the pinned toolchain or case inputs.
