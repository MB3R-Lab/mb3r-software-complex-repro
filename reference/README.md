# Checked-in reference outputs

These files are generated by `make reproduce-paper-update` (or accepted from a completed CI artifact) and verified by `make reproduce-paper`.

The four case directories cover OpenTelemetry all-blocking/async semantics and Social Network norepl/repl modes. Each contains the unchanged published-result replay plus a separate `criticality/` report with complete endpoint-specific service/edge rankings. `FULL_COMPARISON.md` is the readable comparison with every row of both published tables; `comparison.json` contains the same rows plus aggregate error and correlation statistics.

JSON references are semantic normal forms: volatile timing, machine-local paths and references, identifiers derived from platform-specific artifact bytes, and Procrustes' non-semantic choice of one `OTEL_*` field as instrumentation evidence are normalized. Valid zero-value identifiers mark fields derived from platform-specific raw bytes. The source document is retained, as are contracts, topology, predicates, simulation parameters, profile results, criticality rankings, and comparisons. The normalization rules and SHA-256 digests are recorded in `manifest.json`.

Do not edit individual reference files by hand. Update them only after reviewing changes to the pinned toolchain or case inputs.
