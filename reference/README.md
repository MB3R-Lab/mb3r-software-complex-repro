# Checked-in reference outputs

These files are generated by `make reproduce-paper-update` and verified by `make reproduce-paper`.

JSON references are semantic normal forms: volatile `generated_at` / `recompute_duration_ms` values, machine-local artifact paths, and Procrustes' non-semantic choice of one `OTEL_*` field as instrumentation evidence are removed. The source document is retained, as are contracts, topology, predicates, simulation parameters, results, confidence intervals, and sweep boundaries. The normalization rules and SHA-256 digests are recorded in `manifest.json`.

Do not edit individual reference files by hand. Update them only after reviewing changes to the pinned toolchain or case inputs.
