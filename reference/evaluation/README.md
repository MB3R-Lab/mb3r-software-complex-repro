# Extended evaluation references

- `decision.json` records the OpenTelemetry Demo SLO decision sequence: accepted baseline, regressed replica-removal candidate, and independently re-evaluated remediation.
- `validation-matrix.json` records controlled Procrustes diagnoses, exact Bering trace-discovery sets, Sheaft analytical oracles, and the rejected unsupported handoff contract.

Both files are deterministic for the pinned toolchain, configurations, trials, and seeds. Runtime and peak-memory measurements are intentionally not checked in because they describe the machine executing `--cost-profile`.
