# Release v1.3.3

One release number now identifies the demonstration repository, its packaged
toolchain, the GitHub release, and the Docker image:

```text
ghcr.io/mb3r-lab/mb3r-software-complex-repro:v1.3.3
```

`toolchain-lock.json` stores the single release version in `toolchain.version`.
Its lock-file schema is now 1.1.0: the redundant `artifact.version` field has been
removed. Component versions and exact source pins are unchanged: Procrustes
0.1.0, Bering 1.0.0, and Sheaft 1.3.1.

The old `v1.3.2` release and `artifact-1.2.0` image remain historical publications;
neither is repointed. New usage instructions consistently reference `v1.3.3`.

Run `docker compose run --rm demo` to replay the observed operation and preserve
reports under `output/operation-walkthrough/`. This packaging change does not
change the experiment, failure model, component code, or numerical references.
Only release provenance fields in reference summaries advance to 1.3.3.

CI checks the single-version invariant, source replay, reviewer container, and
anonymous download and execution of the published image. The documented scope
and limitations of the six-state operation validation are unchanged; see
[the operation walkthrough](../docs/operation-walkthrough.md).
