# Release v1.3.4

This release pins Procrustes 0.1.0 (`39f76000f8a39c971155e08ebffde829b525911b`), Bering 1.1.1 (`dccd1bca39b6ee85a79e5e245bdd2e727f0da1a3`), and Sheaft 1.3.2 (`686a602f4e7b71f3612f1810885e29dd66c8733a`). Bering's published 1.1.1 image digest is recorded in `toolchain-lock.json`. The packaged tools add an explicit OBI collection-source handoff and support declared OBI input; the archived cases continue to use their original inputs and semantics.

`toolchain.version` is `1.3.4`, while `toolchain.reference_release` remains `1.3.3`. The four published-study case references, historical operation reference, case manifests, and numeric checks remain unchanged. The current operation has its own [v1.3.4 result and provenance](../reference/operation-v1.3.4/provenance.json), frozen from Actions run 40639395787 using Bering 1.1.1's full discovered graph. It retains the same archived HTTP/trace evidence, required RPC calls, seed, trials, oracle and policy thresholds.

Bering 1.1.1 also discovers a catalog-to-database dependency in that archived trace. The database is ineligible for the selected service-failure profile, and the three declared RPC calls remain mandatory. Sheaft samples all sorted edge IDs, including this additional edge, so its fixed-seed Monte Carlo realization differs slightly from the 1.3.3 operation result. A separate Actions diagnostic removed only that node and edge in copies and restored all four historical availability values and both component-importance records exactly. The new reference is the unmodified full-graph result, not the diagnostic copy. The four published-study cases continue to compare strictly against their unchanged historical references.
